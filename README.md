Aplicația "Task Scheduling System" are ca scop programarea și planificarea unor task-uri specifice. Proiectul are două componente: server și client. La partea de server, acesta primește de la client un mesaj de autentificare ce conține adresa MAC a clientului și parola acestuia și le stochează într-un fișier xml. La partea de client, am implementat o interfață grafică folosind Qt. Prin intermediul interfeței clientul poate trimie task-uri către server pentru a fi implementate de acesta și trimite parola.
